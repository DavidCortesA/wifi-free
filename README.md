# WiFi Gratis 📶✝️

Broma para los hermanos: un cartel con un QR que dice "Escanea para conectarte al WiFi" abre esta página, que finge conectarse a la red y luego revela **"La única conexión que necesitas es Jesús"** con confetti y letras animadas.

## Desarrollo

```bash
npm install
npm run dev
```

## Deploy

Importa el repo en [Vercel](https://vercel.com/new): detecta Astro solo, sin configuración extra.
